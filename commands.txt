Setup once (or after proto changes):
export PATH="/opt/homebrew/bin:$PATH:$(go env GOPATH)/bin"
go install google.golang.org/protobuf/cmd/protoc-gen-go@latest
go install google.golang.org/grpc/cmd/protoc-gen-go-grpc@latest
make clean && make proto
Start master (Terminal 1):
cd cmd/master
go run main.go
Start first chunkserver (Terminal 2):
cd cmd/chunkserver
go run main.go --port 8080
Start second chunkserver (Terminal 3, optional but useful for replication):
cd cmd/chunkserver
go run main.go --port 8081
Start client (Terminal 4):
cd cmd/client
go run main.go
Inside client prompt (gfs>), try:
create demo.txt
write demo.txt 0 hello
read demo.txt 0 5
exit



For rereplication -> initiateReplication()-> master/utils.go, monitorChunkReplication()->master/monitor.go
                    chunckCommand class-> api/proto/chunk_master/chunk_master.proto
                    info about chunck, master, operation logs structure-> internal/master/types.go


command to run docker images-> docker compose up -d --build
docker compose exec client /usr/local/bin/gfs-client --config /app/configs/docker/client-config.yml
